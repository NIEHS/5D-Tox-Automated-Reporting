Headline. The PFHxSAm package supplied to this project is the February 2026 DTT method applied to the 2021-era NIEHS-10 study. That method is published only as the "Analysis Pipeline Evaluation" bundled with NIEHS-12/13. It explains every discrepancy found against the published NIEHS-10 report: the PCA, the gene-expression BMDs and the apical BMDs.

Packaging defects found

  • RR-8: C11042_Appendix.doc is actually a .docx.
  • NIEHS-02: the .bm2 (2018, 21 animals, 100 permutations) and the JSON (2021, 19 animals, 10,000 permutations) are different analyses; the exported result files match the JSON.
  • NIEHS-03: the "JSON format" project file is actually a Java-serialised .bm2.
  • NIEHS-05: BMDs_code_package.docx is a zip and Model_Parameters.docx is an Excel workbook.
  • NIEHS-07…10: the GO annotation zips are labelled Affymetrix GPL1355 (left over from G1) and contain no S1500 probe IDs. The genomics project contains three other chemicals. NIEHS-08 also includes a stray Word lock file.
  • NIEHS-12: the rat genomic project's top-level curve-fit prefilter list holds the mouse results; the rat BMD results point to their own embedded rat prefilters.
  • NIEHS-13: the rat raw-count archive is named …Rat_Study,zip (comma, no extension).

What this means for the report tool

  1. "The published method" is not one method. Four distinct gene-expression configurations and two apical engines occur across 12 reports, and the switches happen within report families (NIEHS-02/03 vs 04–06). Validating against a published report means reproducing that report's generation, so validation needs a method profile per report (engine, version, prefilter, BMR, category filters), not one global setting.
  2. The supplied package is the current DTT method applied to a G2 study. Its settings (No0, Williams with no fold filter, curve-fit 1.581 SD, model averaging at 25% RD, BMDExpress 3.20.0156) match the February 2026 DTT method in the NIEHS-12/13 pipeline evaluation exactly. That explains every PFHxSAm discrepancy found so far: PCA (No0 probe subset), gene-expression BMDs, and apical BMDs (BMDExpress instead of BMDS 2.7). Its one addition is a clinical chemistry apical BMR of 25% RD instead of 1 SD.
  3. The forward method is the DTT method, and it is still moving. Published DCB reports use curve-fit 2 SD (3.20.0119); the evaluated method uses 1.581 SD (3.20.0141); the supplied package uses 3.20.0156. No published report yet uses the 1.581 version, so the pipeline evaluation (20 chemicals, EPA comparison, eFDR) is the closest published reference for it. NIEHS-10 remains the reference for the G2 method, validated with modified BMDS 2.7. The evaluation covers BPAF and triclosan, which this project already holds data for.
  4. Ingestion must verify by content and provenance, not by filename. Several packages contain mislabelled types, non-matching bm2/JSON pairs, multi-chemical projects and cross-species objects. Analyses should be selected by their recorded settings, version and data source.
