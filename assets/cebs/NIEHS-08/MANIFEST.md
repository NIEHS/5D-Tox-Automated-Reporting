## Key facts

- 1,1,2,2-Tetrahydroperfluoro-1-dodecanol (10:2 FTOH), study C04051-01, male and female Sprague Dawley rats, gavage, 0–475 mg/kg (10 groups), liver + kidney.
- Same package generation, methods and shared 16-experiment PFAS project as NIEHS-07 (see there).

## Package issues

- Same GPL1355 annotation mislabel and shared multi-chemical project as NIEHS-07.
- The Animal and FASTQ Metadata zip contains a stray Word lock file (~$…docx).
