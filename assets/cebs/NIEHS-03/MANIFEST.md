# NIEHS-03: NIEHS Report on the In Vivo Repeat Dose Biological Potency Study of tert-Butylphenyl Diphenyl Phosphate (CASRN 56803-37-3) in Male Sprague Dawley (Hsd:Sprague Dawley® SD®) Rats (Gavage Studies)

Source: https://cebs.niehs.nih.gov/cebs/data/publication/NIEHS-03 (DOI 10.22427/NIEHS-DATA-NIEHS-03)
Downloaded 2026-10-01: 33 of 33 listed files

## Key facts

- tert-Butylphenyl diphenyl phosphate (BPDP), study C10978, male Sprague Dawley rats, gavage, 0–1032.5 mg/kg (6 groups).
- Same platform and methods as NIEHS-02: Affymetrix GPL1355 microarray, BMDExpress 2.30.0507 run 2021-11-04 on 19 animals, Williams (10,000 perm) + fold 1.5 → 8-model lowest-AIC BMD (1 SD) → GO BP + gene-level categories. Apical: modified BMDS 2.7.

## Package issues

- The file named 'BMDExpress Project File (JSON format)' is not JSON — it is a second copy of the Java-serialised .bm2 (same 2021 analysis). There is no JSON export in this package.
