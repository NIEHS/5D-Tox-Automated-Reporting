## Key facts

- Isodecyl diphenyl phosphate (IDDP), study C20299, male Sprague Dawley rats, gavage, 0–1054.2 mg/kg (6 groups).
- Affymetrix GPL1355 microarray. Unlike 02/03, the published analysis is the ORIGINAL 2018 one: BMDExpress 2.20.0151 run 2018-05-01 on 20 animals, Williams with only 100 permutations + fold 1.5 → 8-model lowest-AIC BMD → GO BP (plain and deduplicated) + gene-level categories. bm2, JSON and exported text all agree. Apical: modified BMDS 2.7.
