# NIEHS-05: NIEHS Report on the In Vivo Repeat Dose Biological Potency Study of Isopropylated Phenyl Phosphate (CASRN 68937-41-7) in Male Sprague Dawley (Hsd:Sprague Dawley® SD®) Rats (Gavage Studies)

## Key facts

- Isopropylated phenol phosphate (IPP), study C10866B, male Sprague Dawley rats, gavage, 0–611 mg/kg (5 groups).
- Same as NIEHS-04: BMDExpress 2.20.0151 run 2018-05-02 on 17 animals, Williams 100 permutations + fold 1.5, 8-model lowest-AIC BMD. bm2/JSON/text consistent. Apical: modified BMDS 2.7.

## Package issues

- 'BMDs code package' is published as BMDs_code_package.docx but is actually a zip (the python bmds package); 'Model Parameters' is published as Model_Parameters.docx but is actually an Excel workbook. Both open only after renaming.
