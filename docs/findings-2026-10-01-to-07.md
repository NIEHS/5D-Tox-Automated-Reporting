# Issues found and fixed, 2026-10-01 – 10-07

From the start of the command-line (no web UI) work through folding in the published NIEHS reports
and their CEBS data. The reports are the reference: we check the code against what NIEHS published.

## Running without the web UI

- **Methods built from an empty context after a restart.** The Methods context read fingerprints held only in memory. After a server restart it silently used protocol defaults. It now loads them from disk.
- **Summary and approval in the headless flow.** The saved Summary wasn't rendered, and approving materialized apical sections failed. Both now work.
- **Process ignored the study's view.** It didn't honour the session's default view filters; it now does.
- **Unnamed or gene-expression `.bm2` misclassified.** These files were classified by filename. They're now classified by content and chip.
- **Metadata inference outside the gateway.** The LLM metadata inference could call outside the walled NIEHS gateway. Both repos now fail closed to the gateway.

## Hard-coded report facts

- **Captions.** They said "Male and Female Rats … Administered … for Five Days" for every study.
- **Species.** Narratives always said "rats", and the BMD prompt called every study "subchronic (90-day)".
- **Study design.**
  - Methods group sizes were fixed at 5 and 10.
  - Strain, route, vehicle and duration came from LLM defaults (5 days, gavage, corn oil). That is where the BPAF and Triclosan values came from.
  - These now come from the data. The one logged fallback is the standard design.
- **Units.**
  - "mg/kg" appeared in ppm studies.
  - Concentration units were a literal "ng/mL".
  - Inhalation studies said "postdose".
- **Footnotes and narrative text.**
  - The attrition footnote always said "study day 1".
  - Text claimed "without signs of overt toxicity" with no clinical observation data.
  - Signs onset now comes from the clinical observations.
- **Another study's content in the template.**
  - Appendices A and F carried PFHxSAm's own content into every report.
  - NIEHS-10's organ, sex and endpoint filters lived in the shared template and hid data in other studies. For example, NIEHS-13's female-only organ weight table rendered as "pending". They now live in a NIEHS-10 study overlay.
- **Missing data domains.** They weren't stated as "not evaluated".

## Statistics

- **Wrong pairwise tests.** The apical pairwise test was always Java Dunnett, and its p-value was non-monotone (an 8 SD difference gave p = 0.44). Footnotes claimed Williams, Shirley or Dunn tests that never ran. The NTP procedure is now implemented in Python, and published markers agree in 4,126 of 4,142 cells across NIEHS-02..13.
- **Relative organ weights** had no statistics and no BMDs.
- **Simulation noise.** The last Williams/Shirley step was simulated, which dropped a published `*` at p = 0.0495. It's now exact.
- **NOEL** defaulted to the control or top dose when it should have been "ND".

## Which animals are counted

- **Biosample animals in body weights.** They were mixed into the body weight data. Published n always equals the Core count, which our data now reproduces.
- **Cohort spelling.** Only "Biosampling Animals" was recognised. NIEHS-07/12/13 write "Biosample Animals", so NIEHS-13's scheduled biosample sacrifices were reported as deaths.
- **Studies with no cohort column** (NIEHS-02..06 and RR-8) got an empty body weight table and no group sizes.
- **Clinical observation incidence** counted all cohorts. It now counts Core only.

## BMDs

- **ToxicR BMDs not shown everywhere.** BMDs filled in by ToxicR now reach every report format, with the inferred BMR footnoted.
- **Wrong acceptance criteria.** Appendix D described BMDS 2.7 rules this pipeline never runs. The NIEHS defined-category filter is now applied and stated, and it reproduces every published NVM.
- **BMD lookup crashed** on inline objects in the `.bm2`.
- **Precision varied** within a report. There is now one BMD precision report-wide.
- **Body weight gain** wasn't derived. It's now in the table, the BMD summary and the narrative.

## Tables and number formatting

- **Decimals.** Mean ± SE decimals were chosen by magnitude rather than per endpoint. Total protein and nRBC printed the wrong decimals.
- **Concentrations** weren't at 3 significant figures.
- **LOEL/NOEL** printed as floats.
- **Body weight table rows.**
  - Responsive intermediate days were missing.
  - Day cells had no significance markers.
  - BMDs were keyed across sexes, so a row could show the wrong sex's BMD.
  - A rounded zero printed as "-0.0".

## Genomics

- **GO tables** were ranked by median instead of 5th percentile.
- **Top-10 genes** came from raw unfiltered probes instead of BMDExpress's gene-level analysis.
- **Gene fold change** used the median over probes; published uses the mean.
- **GO up/down counts** were wrong in 25 of 40 cases.
- **Organ and sex** were parsed from experiment names. The heart code HE was inferred as "blood", which turned heart into blood throughout the NIEHS-13 genomics text.

## Metadata and re-integration

- **Approved metadata lost.** It lived only inside `integrated.json`, so `--reintegrate` silently threw it away.
- **Approving metadata** didn't refresh the genomics sidecar.
- **Malformed LLM JSON** got no retry. The proxy caches identical requests, so any retry has to change the prompt.

## Ingesting the published packages

- **Converters added for:**
  - CEBS Key/Data workbooks;
  - NIEHS-02..05's database-export layout, which needed a cohort rule ("Original Animals");
  - the bundle-only lab blood/tissue concentration workbook.
- **Test fixtures.** The old "golden" fixture paired the 2026 PFHxSAm inputs with a report those inputs didn't produce. It's now a regression fixture. Reference fixtures come from published packages: NIEHS-02, -10, -12 and -13.
- **Published reports broken down.** All published reports (RR-8, NIEHS-02..13) are split into sections, tables and figures from their Bookshelf bundles.
- **Blood/tissue concentration tables.**
  - The data wasn't ingested.
  - Once ingested, it flowed into the apical statistics and the BMD summary.
  - It now has its own table by study day, with the BD, half-LOD, Dixon outlier and marker rules. The table matches 359 of 364 published cells; the 5 differences are NIEHS-12's own printing.

## Data leaving the system

- The genomics chart sent BPAF and Triclosan gene lists to the public Enrichr service. It's now off unless `BMDX_ALLOW_ENRICHR=1` is set.

## Method hard-coded rather than declared (ADR-0027)

- **Scattered settings.** Every method setting was a constant in code, with the text describing it as a separate literal.
- **Wrong-era fallback.** The BMR fallback carried the DTT method's clinical chemistry value (25% relative deviation, not 1 SD).
- **UI and CLI overrode the method** by hard-coding median GO ranking.
- **Methods overclaimed** outlier exclusion.
- **No check** that a `.bm2` analysis's recorded settings matched the intended method.
- **What's in place now:**
  - versioned profiles (`ntp-5day-2025`, `ntp-5day-2021`) pinned per study;
  - footnotes, Methods and Appendix D generated from the profile;
  - a `.bm2` mismatch check;
  - each published report tested under its own profile;
  - studies follow the newest profile by default; `--method-profile NAME` fixes one.

## Study design facts

- **Design facts lost on re-integration.** `--design` wrote only onto `integrated.json`, which every integration rebuilds. The stated design is now kept in `study_design.json` and re-applied at each integration.
- **BPAF and Triclosan design.** No delivered file records strain, route or vehicle. On 2026-10-07 the user stated the standard design: Sprague Dawley rats, gavage, corn oil, 5 days. That is now recorded as stated, not as a fallback.
- **Supplier designation.** The title's "(Hsd:Sprague Dawley® SD®)" could only come from the request body. It's now front matter (`strain_designation`), settable from the Configure screen or `--front-matter`.

## Still open

- **Methods text is wrong in places.** The internal-dose prompt hard-codes "LC-MS/MS, study day 5", and other Methods prompts carry older-era text.
- **Inhaled-dose normalization.** Rows normalized by the theoretical inhaled dose aren't built, because no file records that dose.
- **Dose unit fallback.** `wizard-ui/src/steps/Process.tsx` defaults the dose unit to "mg/kg".
- **Animal report counts** include NIEHS-13's biosample animals as core.
- **BPAF and Triclosan still missing:**
  - the Background section, which needs the host;
  - authors and contributors for About This Report;
  - the eFDR figure.
- **Decision pending:** whether to fix NIEHS-13 (`DTXSID1020431`) to `ntp-5day-2025`. It currently follows the newest profile.
