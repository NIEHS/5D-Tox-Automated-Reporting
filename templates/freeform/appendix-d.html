The benchmark dose (BMD) model recommendation and selection methodology applies a fixed set of rules to each fitted model. Each rule classifies a model outcome as Viable, Nonviable, Nonreportable, or a Failure, and the resulting bin placement determines whether a model is eligible for recommendation. Table D-1 lists the rules, the criterion each evaluates, the numerical threshold applied (where one is used), and the bin the model is placed in when the rule fails.
