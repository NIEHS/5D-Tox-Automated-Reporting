Apical endpoints were modeled in BMDExpress 3 with the ToxicR engine. Where the study's BMDExpress analysis modeled an endpoint, its recorded result is used; an endpoint that analysis did not model was fit with the same engine by Laplace model averaging, at the benchmark response stated with the benchmark dose (BMD) summary table.

Every modeled response, whichever its source, was then subjected to the acceptance criteria tabulated below, the defined-category filter applied to model-averaged apical BMDs. Model averaging weights each model's fit by its posterior probability, so no single model is selected; the criteria apply to the averaged curve. A response that fails any criterion is reported as having no viable model (NVM), as is an endpoint that met the statistical criteria for modeling but for which no model average could be obtained. A BMD that passes the criteria but falls below the low-dose limit lies outside the range the data can support; it is reported as less than that limit, and its benchmark dose lower confidence limit (BMDL) is not reported. The settings each BMDExpress analysis recorded follow the criteria.
